# ПРОПУСТИЛ! / Dog Fight Club — v0.2 (дуэли с друзьями)

Слот-баттлер «собака против собаки»: React + TypeScript + Vite, Telegram Mini App.
v0.1 — боевая песочница (бот, вдвоём на одном экране, debug, симуляция).
v0.2 — **асинхронные дуэли с друзьями** через Telegram: сервер на Cloudflare Workers + Durable Objects,
вызов в чат, ходы по очереди, уведомления бота, реванш, рейтинг чата. Запуск и устройство — **docs/DUELS.md**.

## Быстрый старт

```bash
npm install
npm run dev          # http://localhost:5173  (с телефона в той же сети: npm run dev -- --host)
npm test             # 51 тест: движок + UI (vitest, jsdom)
npm run build        # typecheck (tsc -b) + production-сборка в dist/
npm run preview      # раздать dist/
npm run simulate -- 10000 1   # CLI-симуляция 10 000 боёв, seed 1
npm run typecheck:server      # типы сервера дуэлей
npx wrangler dev              # игра + сервер дуэлей локально (см. docs/DUELS.md)
```

Требуется Node 20+ (проверено на Node 22).

## Что внутри

| Режим | Как попасть |
|---|---|
| Бой с ботом «Саня» | Меню → **Играть** |
| Вдвоём на одном экране | Меню → **Вдвоём** |
| Правила и таблица символов (из balance.json) | Меню → **Правила** |
| Debug-панель в бою | включить «Debug режим» в меню (или `?debug=1`) → кнопка **Debug** в бою |
| Симуляция N боёв | Debug режим → **Симуляция боёв** |

URL-параметры: `?debug=1` — включить отладку, `?seed=sanya` — фиксированный seed боя.
Клавиатура: `Space` / `Enter` — крутить.

## Архитектура

```
docs/balance.json          ← единственный источник параметров (HP, веса, эффекты, тройки, правила)
src/engine/                ← чистая логика, без React/DOM
  types.ts                 типы домена (BattleState, TurnRecord…)
  rng.ts                   mulberry32, состояние RNG хранится в BattleState (детерминизм/реплей)
  balance.ts               загрузка + валидация balance.json
  combo.ts                 взвешенные барабаны, разрешение комбинации
  battle.ts                takeTurn(state) → { state, record } — чистая функция хода
  session.ts               BattleSession: блокировка ввода, бот, реванш, debug-хуки
  stats.ts                 статистика боя для экрана результата
  simulate.ts              headless-симуляция N боёв с отчётом
src/online/                ← протокол и API-клиент дуэлей
server/                    ← Cloudflare Worker: API, проверка initData, Durable Object, бот
src/ui/                    ← только представление
  presentation.ts          TurnRecord → надписи, позы, всплывающие числа (чистые функции)
  useBattle.ts             таймлайн анимаций хода, синхронизация с сессией
  components/ screens/     React-компоненты, sim.worker.ts — симуляция в Web Worker
scripts/process_assets.py  генерация временных прозрачных спрайтов из вырезок концепта
art/                       исходные материалы пакета (концепты, вырезки) — не бандлятся
```

UI никогда не меняет боевое состояние напрямую: он вызывает `session.trySpin()` и проигрывает
полученный `TurnRecord`. Тот же `takeTurn` используется ботом, симулятором и тестами.

## Правила (как реализованы)

1. Три независимых взвешенных барабана (веса из `balance.json`).
2. Тройка **заменяет** обычные эффекты (`3× удар` = 40, а не 30 + 40).
3. Остальные эффекты суммируются; лечение ограничено максимумом HP.
4. Щит поглощает следующий входящий удар (до своей величины) и исчезает после него
   или в начале следующего собственного хода владельца. Самоурон щитом не блокируется.
5. Порядок хода: сгорание своего щита → лечение → урон противнику и самоурон одновременно →
   получение нового щита → проверка KO (оба ≤ 0 — ничья) → лимит ходов → доп. ходы.
6. Молнии вне тройки дают максимум 1 доп. ход за спин, тройка — 2; подряд не больше 2 доп. ходов.
7. Лимит 40 вращений (суммарно), затем победа по HP или ничья.
8. Бот использует ту же сессию и те же правила — он просто «нажимает кнопку» после паузы.
9. Во время анимации кнопка заблокирована, повторные клики отклоняются сессией (и считаются в Debug).

Параметры `rules` (`maxSpins`, `maxExtraTurnsInRow`, `maxExtraPerMixedSpin`) добавлены в `balance.json`;
при их отсутствии используются значения из ТЗ.

## Графика

Персонажи и символы — **временные** автоматически вырезанные спрайты из низкоразрешённых
вырезок концепта (`scripts/process_assets.py`). Это не финальный арт и не спрайтшиты:
анимации сделаны программно (CSS-keyframes + Web Animations API). Для финала нужны отдельные
спрайты 512×512 / 128×128 / фон 1080×1920 (см. `docs/ART_GUIDE.md`).

Подробности — `docs/IMPLEMENTATION_PLAN.md` и `docs/REPORT.md`.
