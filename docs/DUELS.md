# Дуэли с друзьями — сервер и запуск

## Как это работает для игрока
1. В меню **«Вызвать друга»** → Telegram открывает выбор чата → в чат уходит карточка
   «Саня вызывает тебя на бой!» с кнопкой **«Принять вызов»**.
2. Друг жмёт кнопку → открывается игра → **«Принять вызов»** → жребий решает, кто бьёт первым.
3. Ходят по очереди, когда удобно. Если соперник не в игре, бот пишет ему «Твой ход» с кнопкой «Ударить в ответ».
4. Нокаут/победа по очкам/сдача → оба видят результат, бот присылает итог. **«Реванш»** у обоих ведёт в один и тот же новый бой (первым бьёт проигравший).
5. **«Мои дуэли»**: список боёв («твой ход!» сверху) и **«Чемпион чата»** — рейтинг побед для дуэлей, принятых из группы.

Сообщения от бота — только по согласию (`requestWriteAccess` спрашивается при вызове/принятии).

## Архитектура
```
Cloudflare Worker "dogfight" (wrangler.toml)
├─ статика: dist/ (та же игра)          GET /, /assets/*, /share.jpg
├─ API: server/worker.ts                /api/*  (Authorization: tma <initData>)
├─ webhook бота                         POST /tg/webhook (/start → кнопка «Драться»)
└─ Durable Object GameStore (SQLite, бесплатный тариф)
     duel:<id>   — бой; все ходы выполняются здесь последовательно (атомарно)
     user:<id>   — список дуэлей игрока
     chat:<inst> — рейтинг чата
```
- **Сервер авторитетный**: seed и состояние ГСЧ хранятся только на сервере и вырезаются из ответов,
  барабаны крутит `takeTurn` того же движка `src/engine`.
- **Идемпотентные ходы**: клиент шлёт `expected = spinCount`; повтор/двойной тап возвращает `stale` и ничего не крутит.
- **Проверка личности**: подпись `initData` (HMAC-SHA256 с токеном бота), срок 48 ч.
- Клиент опрашивает бой каждые 2,5 с, пока ход соперника (10 с в свой ход, пауза в фоне) и проигрывает новые ходы той же анимацией.
- Без Telegram или без сервера (например, GitHub Pages) кнопки дуэлей просто не показываются — одиночная игра работает.

## Запуск на Cloudflare (один раз, ~10 минут)
1. **Новый токен бота.** В @BotFather: `/mybots` → бот → **API Token** (или `/revoke` → новый). Никому его не пересылайте.
2. **Аккаунт Cloudflare.** Зарегистрируйтесь на dash.cloudflare.com (бесплатно, карта не нужна).
3. **Создать Worker из GitHub.** *Workers & Pages* → **Create** → **Import a repository** (Connect GitHub) →
   разрешите доступ к `estepanov-blip/dogfight` → выберите репозиторий.
   - Project name: **`dogfight`** (должно совпадать с `name` в `wrangler.toml`)
   - Build command: **`npm ci && npm run build`**
   - Deploy command: **`npx wrangler deploy`**
   - Root directory: `/`, production branch: `main`
   → **Deploy**. Через 1–2 минуты будет адрес вида `https://dogfight.<ваш-поддомен>.workers.dev`.
4. **Секрет.** Worker → *Settings* → *Variables and Secrets* → **Add** → Type **Secret**,
   Name **`BOT_TOKEN`**, Value — токен из шага 1 → **Deploy**.
5. **Настроить бота.** Откройте в браузере `https://dogfight.<ваш-поддомен>.workers.dev/api/setup` —
   ответ `"ok": true` (ставит webhook, кнопку «Драться» в чате, команду /start).
6. **Mini App.** В @BotFather: `/mybots` → бот → *Bot Settings* → *Configure Mini App* → URL из шага 3.
7. Перезапустите Telegram, откройте бота → **Драться** → **Вызвать друга**.

Каждый push в `main` дальше выкатывается автоматически.

## Локальная разработка
```bash
npm install
printf 'BOT_TOKEN=123456:TEST-token\nTG_API_BASE=http://127.0.0.1:8788\n' > .dev.vars
node scripts/qa/mock-telegram.mjs 8788 /tmp/tg-mock.jsonl &   # поддельный Bot API
npm run build && npx wrangler dev --port 8787
python3 -I scripts/qa/duel_e2e.py http://127.0.0.1:8787 /tmp/tg-mock.jsonl /tmp/duel-shots
```

## Лимиты и ограничения
- Бесплатный тариф Workers/Durable Objects рассчитан на ~100 тыс. запросов в сутки; один открытый бой при ожидании
  делает ~1 запрос в 2,5 с — для теста с друзьями с запасом.
- `*.workers.dev` из части российских сетей может открываться нестабильно; лечится своим доменом на Cloudflare.
- Пол игрока Telegram не сообщает — тексты бота нейтральные, в интерфейсе местами «победил/отправлен».
- Нет таймаута хода: брошенный бой висит, пока кто-то не сдастся.
