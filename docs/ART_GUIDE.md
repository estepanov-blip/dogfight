# Art guide
Фотореалистичные мемные собаки, красные/синие перчатки, темный ринг, желтая CTA, крупные комиксные надписи. Целевые размеры: персонажи 512x512 transparent PNG, символы 128x128, фон 1080x1920. Текущие вырезки имеют исходное низкое разрешение и фон; poses — только референсы. Для финального арта нужны отдельные чистые спрайты. Оригинальный Telegram стикерпак не использован.
