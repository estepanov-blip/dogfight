# Combat Sandbox
Создай React + TypeScript + Vite приложение с адаптивным портретным UI. Используй balance.json как источник параметров. Отдели чистую боевую логику от UI. Реализуй меню, бой против бота, локальный режим на двоих, результат, реванш и журнал.
## Правила
Три независимых взвешенных символа. Тройка заменяет обычные эффекты. Суммируй остальные эффекты; лечение ограничено 100 HP. Щит поглощает следующий входящий удар и исчезает после него или перед следующим собственным ходом. Урон и самоурон применяются одновременно; двойной KO — ничья. Дополнительные ходы: максимум два подряд, одиночные молнии дают один ход за вращение. Лимит 40 вращений на бой, затем победа по HP или ничья. Бот использует те же правила. Блокируй кнопку во время анимации.
## Графика
Используй временные вырезки из assets; при необходимости замени их простыми CSS-заглушками. Idle — покачивание; punch — рывок; hit — отскок; KO — поворот и падение; block — вспышка щита; heal — зеленый эффект. Не выдавай концепт-листы за готовые спрайтшиты.
## QA
Тесты всех троек, смешанных комбинаций, щита, лимита HP, дополнительных ходов, ничьей, реванша и блокировки повторного клика. Debug: принудительные комбинации, seed RNG, симуляция 10000 боев с отчетом о длительности в ходах, win rate и частоте эффектов.
## DoD
npm install; npm run dev; npm run build; тесты проходят. README с командами. Telegram/backend вне этапа. После приемки — серверное авторитетное состояние, проверка Telegram initData, идемпотентные ходы и opt-in вызовы.
