# Combat Sandbox v0.1 — план реализации

## Цель
Проверяемый в браузере прототип боя: правила из TECH_SPEC, параметры из balance.json, визуальная
обратная связь уровня концептов, мобильный портретный UI, отладка и массовая симуляция.

## Принятые трактовки неоднозначных правил
- **Щит** — величина, которая вычитается из *одного* следующего входящего удара; остаток сгорает.
  Удар с 0 урона щит не тратит. Щит сгорает в начале любого следующего хода владельца, *включая доп. ход*.
- **«Одиночные молнии дают один ход за вращение»** — 2 молнии вне тройки дают 1 доп. ход.
- **«Максимум два подряд»** — не более 2 доп. ходов в одной серии (т. е. до 3 спинов подряд).
- **Ход** — одно вращение; лимит 40 считается суммарно для обоих.
- **Лечение и самоурон** — сначала лечение (с лимитом), затем одновременно урон и самоурон.
- **Реванш** — новый seed, первым ходит другой боец.
