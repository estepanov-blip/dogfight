## Найдено и исправлено в ходе проверки

1. Спрайты пака стояли низко и выглядели мелкими: нижнюю часть арены перекрывает панель барабанов. Добавлен кадр `frame-waist`, нижний срез теперь уходит под барабаны.
2. При первом увеличении головы зеркальной пары перекрывались. Подобран масштаб `min(58cqh, 64cqw)`: торс по размеру как у Сибы и Буля, головы не сходятся.
3. В нокауте поворот на 84° показывал срез спрайта по шортам. Для кадра по пояс сделано отдельное падение: завал на 38° с уходом под край ринга.
4. На маленьком экране бойцов пака ограничивала высота арены (184 px против 310 px у Сибы). Ограничение ослаблено до 226–230 px.
5. В меню боец пака выглядел мелким рядом с Булем. Добавлен кадр по пояс и для меню; на экране выбора подпись больше не наезжает на голову.
